# Учёт книг

Консольное приложение для ведения списка книг. Можно добавлять книги с названием, автором, годом издания и жанром, просматривать и удалять записи, а также фильтровать список по жанру. Фильтр не зависит от регистра. Для книг без указанного жанра используется значение «Без жанра».

Приложение сохраняет список в JSON-файл `books.json`. Если файла ещё нет, он создаётся при первом сохранении книги. Для записей, сохранённых до добавления жанров, жанр считается пустым.

## Требования

- Python 3.12
- `pytest` — необязательно, требуется только для запуска тестов

## Установка

Установите Python 3.12 и проверьте, что он доступен:

```powershell
py -3.12 --version
```

Из корневой папки проекта при необходимости создайте и активируйте виртуальное окружение:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Для запуска приложения внешние библиотеки не нужны. Чтобы запускать тесты, установите `pytest`:

```powershell
py -3.12 -m pip install pytest
```

## Запуск

Из корневой папки проекта перейдите в каталог приложения и запустите точку входа:

```powershell
Set-Location ".\Lesson 3"
py -3.12 main.py
```

Файл `books.json` будет создан в текущем рабочем каталоге — при запуске по инструкции это `Lesson 3`.

## Тесты

Из корневой папки проекта запустите:

```powershell
py -3.12 -m pytest ".\Lesson 3\test_books.py" ".\Lesson 3\test_calc.py"
```
