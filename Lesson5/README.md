# MineShield — сайт базы знаний сервера

Веб-приложение на Flask и SQLite. В нём есть история сервера, сезоны, поиск игроков, карточки, избранное, вход для игроков и администратора.

## Запуск

```powershell
py -m pip install -r requirements.txt
py mineshield.py
```

Откройте <http://127.0.0.1:5000>.

При первом запуске создаётся `server_info.db`; если нет аккаунта `admin`, приложение добавляет демо-администратора:

- логин: `admin`
- пароль: `admin123`

После входа откройте «Пароль» в шапке и замените демонстрационный пароль. Администратор может создавать и удалять аккаунты игроков, задавать им новые пароли, привязывать их к карточкам и редактировать историю, сезоны и карточки. Удаление аккаунта сохраняет карточку, отвязывая её; удалять карточки можно отдельно. Пароли хранятся в виде хешей и не отображаются даже администратору. Игрок может изменить описание своей привязанной карточки и опубликовать объявление на главной.

Для сохранения входа при перезапуске сайта укажите постоянный секрет Flask в `MINESHIELD_SECRET_KEY`. Без него при каждом запуске создаётся новый ключ и текущие сессии завершаются.

## Логотип

Изображение `static/images/logo.png` автоматически показывается в шапке, подвале и на главной странице.

## Избранное и объявления

Избранное сохраняется в `localStorage` браузера, поэтому не привязано к аккаунту и не синхронизируется между устройствами. Объявления игроков публикуются на главной странице сайта; Telegram-уведомления и push-оповещения не отправляются.
